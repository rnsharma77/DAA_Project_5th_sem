🧠 Sorting Algorithm Visualizer

A professional and modern web application for visualizing how various sorting algorithms work — built with HTML, Tailwind CSS, and JavaScript.

📝 Description

The Sorting Algorithm Visualizer is an interactive tool that demonstrates the step-by-step process of popular sorting algorithms.
It allows users to see how arrays are sorted in real-time using visual bars, color-coded transitions, and dynamic controls for speed and array size.

This project is perfect for students, educators, and developers looking to understand sorting algorithms intuitively.

⚙️ Features

Multiple Algorithms: Bubble Sort, Selection Sort, Insertion Sort, Merge Sort, and Quick Sort

Interactive Controls: Adjust array size and sorting speed in real time

Dynamic Visualization: Watch comparisons and swaps as they happen

Live Statistics: Displays total comparisons and swaps performed

Clean UI: Beautiful glassmorphism-inspired design with responsive layout

No Dependencies: Runs directly in your browser — no backend needed

🧩 Algorithms Included
Algorithm	Time Complexity	Space Complexity
🫧 Bubble Sort	O(n²)	O(1)
🧩 Selection Sort	O(n²)	O(1)
🪄 Insertion Sort	O(n²)	O(1)
⚡ Merge Sort	O(n log n)	O(n)
🔥 Quick Sort	O(n log n)	O(log n)
🧠 Visualization Legend
Color	Meaning
🔵 Blue	Unsorted elements
🔴 Red	Elements currently being compared
🟢 Green	Sorted elements
🖥️ Installation & Usage

Clone the repository

git clone https://github.com/yourusername/sorting-algorithm-visualizer.git
cd sorting-algorithm-visualizer


Open the project

No dependencies required — just open index.html in your web browser.

You can also serve it with a local server for better performance:

npx live-server


Interact

Select your preferred sorting algorithm

Adjust the array size and sorting speed

Click Start to visualize the sorting process

Click New Array to randomize the bars

🧮 How It Works

Bars of different heights represent array elements

The algorithm compares and swaps them according to sorting rules

Each comparison and swap is color-coded

Stats for comparisons and swaps update in real time

All animations are handled using asynchronous JavaScript (async/await) and controlled delays for smooth visuals.
